# v3.0.0rc7

- 镜像: ghcr.io/pear-studio/nonebot-dicepp:v3.0.0rc7
- Windows: DicePP-v3.0.0rc7-win64.zip
- 数据变更: no
- 配置变更: no

## Fixed
- 修复 PersonaConfig 缺失 6 个 Story Deck / Front / SA 配置字段，导致所有配置了 persona 的 bot 初始化时抛出 AttributeError 并被禁用。受影响字段：`story_deck_max_injection`、`story_deck_max_entries`、`front_max_campaign`、`front_max_adventure`、`threads_per_front`、`sa_max_rounds`。
- 修复 `background_llm_max_tool_rounds` → `background_llm_max_rounds` 重命名在 PersonaConfig 中遗漏（默认值同步从 1 调整为 10），导致后台 LLM 调用轮次配置不生效。

## Risk Notes
- 这是 rc6 的 bugfix 版 RC，不作为正式生产版本部署。
- 数据变更和配置变更与 rc6 相同（rc7 无新增 schema 变更或配置项变更）。
- rc6 中 persona 模块不可用的用户可直接升级到 rc7 恢复 persona 功能，无需额外迁移步骤。
