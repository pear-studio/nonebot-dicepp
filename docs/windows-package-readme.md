# DicePP Windows 使用说明

欢迎使用 DicePP。Windows 发布包采用单入口，普通用户只需要启动 `DicePP.exe`。

启动后会打开网页管理面板，用于初始化管理员密码、修改配置、查看运行状态、查看日志和管理存档。机器人接入 QQ 后，在 QQ 中向机器人发送 `.help`，收到回复即基本可用。
