# v3.0.0rc4

- 镜像: ghcr.io/pear-studio/nonebot-dicepp:v3.0.0rc4
- Windows: DicePP-v3.0.0rc4-win64.zip
- 数据变更: yes
- 配置变更: no

## Added
- 新增 `user_config` 数据表，用于保存用户级运行设置。

## Changed
- 私聊 `.chat` 间隔设置改为保存到用户级配置中，不再混入用户统计数据。
- Linux Docker 部署文档补充 Dashboard 推荐部署形态，便于核对 `bot` 与独立 `dashboard` service 是否按同一份 compose 部署。
- Dashboard 登录在同一来源连续输错密码后会进入短暂冷却，降低公网暴露时被暴力尝试密码的风险。

## Fixed
- 修复 MiniMax 用量超限、限流和内容过滤错误的分类，减少不可重试错误被反复重试的问题。
- MiniMax/OpenAI provider 探测失败时记录更明确的状态码、错误类型和超时信息，便于定位模型不可用原因。

## Deprecated
- 暂无。

## Risk Notes
- 这是发版链路验证用 RC，不作为正式生产版本部署。
- 本版本会把 Bot 数据库 schema 升级到 v4，并创建 `user_config` 表。升级前建议备份 `data/`。
- 已有私聊 `.chat` 间隔如果仍保存在旧的 `user_stat` 数据中，本 RC 不会自动迁移该值；升级后可能需要用户重新设置私聊 `.chat` 间隔。
- Dashboard 直接公网 HTTP 访问仍会暴露登录密码和会话信息，长期公网使用建议通过反向代理开启 HTTPS。
