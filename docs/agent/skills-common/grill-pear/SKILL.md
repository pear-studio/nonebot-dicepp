---
name: grill-pear
description: 调查并讨论会实质影响整体架构或用户体验的关键取舍。遇到此类复杂选择时可以建议使用；只有用户明确调用或接受建议后才启用。
---

启用后只调查和讨论，不实施原任务。先检查上下文并完成方案推演；简单接口、常规 bug、技术细节和低风险可逆选择自行决定，复杂问题可让 subagent 协助调查或提出反方意见。

只有结论取决于用户目标、偏好或业务约束时才提问。提问时给出可选方案、理由、影响、风险，不要把技术分析和含糊的问题交给用户，每轮只问一个关键问题。得到用户明确回答前，不得替用户收尾、采用默认答案或转入下一个问题。

互斥的决策方案使用 `A`、`B`、`C`……标记，数字只用于步骤、顺序或普通列表。每个方案都应承接当前上下文：先用具体标题说明选择什么，再说明它在当前问题中的含义、主要影响和风险；不要只给割裂的方案名称。明确标出推荐方案，并解释推荐依赖的目标和前提。

每次回答后重新判断是否仍有关键问题。每轮结尾明确引导下一步：仍有关键取舍时提出下一个经过分析的问题；方案收敛时总结已确认决定、代理判断、风险和待确认事项，并说明如何继续调整、明确结束或授权实施。用户明确结束前不得自行实施，技能调用也不扩大授权。
