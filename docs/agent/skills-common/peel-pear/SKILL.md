# Peel Pear

暂停当前任务，帮助用户逐步看清发生了什么，再回到原任务。只补当前需要的上下文，不扩展成系统课程。

## 开始说明

- 记住尚未回答的问题或任务作为返回点；按需只读查看代码、文档或可靠资料，不实施原任务。
- 从现有对话判断起点，不让用户重新描述大量上下文。整体陌生时先用一句普通话说明现实目标或核心冲突；局部陌生时说明该概念与当前问题的关系。
- 第一轮只给核心锚点和几条理解路径，让用户选择从哪里开始。

## 提供理解路径

- 使用 `**A｜标题**`、`**B｜标题**`……标记内容选项；使用 `**R｜已经清楚**` 返回原问题或结束。
- 每个选项承接上文，用一小段话说明要解释什么、它为什么有助于理解当前问题；可以透露少量答案，避免让用户盲选生词。

把这些选项当作一个持续更新的主题池：

- 字母在本次说明中保持稳定，不重复分配。
- 每轮只解释一个主题；多选时按顺序排队。
- 讲过的主题和用户明确表示已清楚的主题可以收起。新主题少量追加，相近问题合并；主题过多时提醒用户清理。

## 逐步推进并返回

- 每轮只讲当前选择的一个知识点，不一口气推进太多，再展示仍待了解的主题和少量新方向。用户不需要复述或接受测试。
- 区分事实、推断、推荐及其前提，不把推荐说成唯一答案。
- 只有用户明确选择 `R` 或要求结束时才退出。存在返回点时重新呈现原任务，不替用户作答。
