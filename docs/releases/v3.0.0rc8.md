# v3.0.0rc8

- 镜像: ghcr.io/pear-studio/nonebot-dicepp:v3.0.0rc8
- Windows: DicePP-v3.0.0rc8-win64.zip
- 数据变更: no
- 配置变更: yes

## Added
- Linux 离线包 `DicePP-vX.Y.Z-linux-amd64-offline.zip`：Release 新增 Linux Docker 离线部署产物，包含 bot 和 dashboard 镜像（zstd 压缩）、`docker-compose.yml` 及部署文档。适用于无法直接访问 GHCR 的服务器环境，通过 `docker load` 导入后即可部署。

## Changed
- `send_reply_segment` 使用内置段数硬限：超出上限时返回明确错误提示，LLM 无法继续追加分段，必须调用 `send_reply` 提交当前结果。
- 移除 `segment_round_callbacks_max` 配置项。已有配置中若包含该字段会被静默忽略，不影响 bot 启动和运行。

## Fixed
- 修复 `.jrrp` 命令因内部 `ChatOrchestrator.chat()` 参数传递不匹配导致 TypeError 崩溃。
- 修复 persona 生活 tick 无槽位匹配时每秒输出 WARNING 日志噪音。
- 修复 DeliveryQueue 发送入库时 `message_type` 硬编码为 CHAT，导致 jrrp 评语等非 chat 场景数据写入类型不一致。

## Risk Notes
- 这是 rc7 的后续 RC 版本，不作为正式生产版本部署。
- 配置变更仅涉及移除 `segment_round_callbacks_max`，无需手动迁移；已有配置中的该字段会被 Pydantic `extra="ignore"` 静默忽略。
- 无数据 schema 变更，升级无需执行迁移脚本。
