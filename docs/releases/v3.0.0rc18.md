# v3.0.0rc18

- 镜像: ghcr.io/pear-studio/nonebot-dicepp:v3.0.0rc18
- Windows: `DicePP-v3.0.0rc18-win64-Portable.zip`、独立 `DicePP-v3.0.0rc18-win64-Setup.exe` 和 `velopack.win-x64.zip`
- 数据变更: no
- 配置变更: no
- 变更范围: runtime, dashboard, deployment
- 自动升级: yes
- 最低 Manager 版本: 1.0

## Changed

- Bot、Manager 与 Dashboard 共用的控制协议和控制凭据迁至无副作用共享包，Manager/Dashboard 启动不再连带加载 Bot 业务模块。

## Fixed

- 修复 Windows Portable 或安装版从 Explorer 双击、登录自启动以及无控制台后台启动时，`stderr` 不存在导致 Loguru 初始化崩溃并弹出 PyInstaller 错误框的问题。
- 修复 Velopack install、update、obsolete 和 uninstall 生命周期 hook 误启动常驻 DicePP，导致 Setup 或更新器等待超时并强制终止进程的问题。

## Risk Notes

- 已采用 contract v2 标准拓扑的 v3.0.0rc17 实例可使用 Manager 自动升级到本版本；升级前仍应保留已验证归档，并确认实例没有未完成的维护事务。
- v3.0.0rc16 及更早版本的 Manager 不识别 contract v2 `velopack.win-x64.zip` / Linux bundle 契约，不能直接自动升级到本版本；必须先手工迁移到 v3.0.0rc17 或更高兼容版本。
- 本版本不包含数据、配置 schema、Compose service、volume 或 network 迁移。
