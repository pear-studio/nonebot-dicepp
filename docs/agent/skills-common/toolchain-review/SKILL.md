# Toolchain Review

复盘当前会话，找出值得改进的 agent 工具、脚本、环境配置或技能说明。只使用会话中的实际证据，不推测未发生的问题，也不为凑数报告无价值事项。

## 检查

- 工具或脚本失败：参数错误、路径失效、依赖缺失、权限或版本问题。
- 环境不匹配：运行时、平台、配置和项目假设不一致。
- 反复失败或绕路：相同问题多次重试、错误方向导致返工、需要用户反复纠正。
- 技能缺口：说明含糊、步骤遗漏、前提或安全边界没有覆盖真实场景。

按影响区分：阻塞任务、明显降低效率、一般体验改进。相似现象合并为一个根因；区分工具链问题与任务本身的正常探索成本。

## 汇报

默认直接向用户简要说明：

- 问题及影响程度。
- 发生了什么，以及支持判断的会话证据。
- 建议改进哪个工具、脚本、配置或技能。

没有值得记录的问题时直接说明。只有用户明确要求写报告或归档时，才写入当前工作区合适的临时或文档目录；写入前说明路径。不要记录密钥、账号、敏感配置或与问题无关的本地路径。
