## Summary

v3.0.0 是 DicePP 发版系统的基线版本。

主要变更：
- **版本号统一**: 运行时版本号从硬编码切换为 `importlib.metadata` 派生，与 `pyproject.toml` 一致
- **可复现构建**: Docker 构建切换为 `uv sync --frozen`，使用 `uv.lock` 锁定依赖
- **GHCR 镜像发布**: 引入 GitHub Actions workflow (`release.yml`)，tag push 自动构建并推送镜像
- **镜像部署支持**: `docker-compose.yml` 同时支持 `image:`（镜像模式）和 `build:`（源码模式）
- **版本分发**: `docker-compose.yml` 作为 GitHub Release asset 分发，无需 git clone

## Risk Notes

- 此版本为发版系统自身的基线，不包含数据库 schema 变更
- 不包含配置格式变更
- 不包含数据迁移
