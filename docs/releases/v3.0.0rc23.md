# v3.0.0rc23

- 数据变更: no
- 配置变更: no
- 变更范围: dashboard, manager
- 自动升级: yes
- 最低 Manager 版本: 1.0
- Linux Manager handoff 协议: 1

## Added

- 无。

## Changed

- Dashboard 版本更新页改为按检查、下载和安装顺序展示当前进度，将更新设置、产物信息和历史记录分开呈现；刷新页面或遇到已有下载任务时会继续显示实际状态。
- Dashboard 不再提供运行数据库原始表浏览；常用运行信息继续由概览、Persona、运行监控和审计日志按用途展示，查询数据库审查仍保留在内容管理中。

## Fixed

- 修复被后续成功升级取代的中断事务仍反复触发启动恢复、阻止后续升级和 Runtime 操作的问题。
- 修复 Manager 在启动恢复期间单独重启时可能错误停止 Runtime，并导致 Linux Bot 持续离线的问题。
- 修复版本更新页把成功事务说明显示为失败原因、下载进度不清楚，以及重复点击下载容易被误认为失败的问题。

## Deprecated

- 移除 Dashboard 通用运行数据库浏览页面及对应接口；原始数据库排障请使用开发工具或 SQLite 工具。

## Risk Notes

- 已采用 v3.0.0rc22 标准部署的实例可在 Dashboard 中由管理员确认后升级到本版本；Linux 使用 Manager handoff v1，Windows 失败时保留安装根目录的一次性 `DicePP-Recover.cmd`。
- 本版本不包含数据、配置 schema、Compose service、volume、network 或 deployment schema 迁移。
- Final Candidate 必须通过与 v3.0.0rc22 真实发布字节绑定的 Windows/Linux 升级、恢复和回退矩阵后才能晋升。
