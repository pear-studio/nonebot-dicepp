# v3.0.0rc12

- 镜像: ghcr.io/pear-studio/nonebot-dicepp:v3.0.0rc12
- Windows: `DicePP-v3.0.0rc12-win64-Portable.zip`、独立 `DicePP-v3.0.0rc12-win64-Setup.exe` 和 Velopack feed
- 数据变更: no
- 配置变更: no
- 变更范围: runtime, dashboard, documentation
- 自动升级: yes
- 最低 Manager 版本: 1.0

## Fixed

- 修复 Linux 全新部署时 Dashboard 因 `config/` 只读挂载反复重启、无法启动的问题。Dashboard 不再在启动时写入 `config/user.json`，配置写入统一由 Manager 执行。

## Changed

- Linux 部署文档补充发布包断点续传下载方式，以及版本升级时 Compose 文件必须整体替换的说明。

## Risk Notes

- 本 RC 是 Windows 与 Linux 真实升级验收的目标版本，据此声明 `自动升级: yes`。两平台升级验收完成前，生产实例升级到本版本前仍建议先在 Dashboard 创建并验证归档。
- 本版本不含数据布局、配置 schema、Manager 协议或部署拓扑变更；已采用 `v3.0.0rc11` 标准拓扑的实例可由 Manager 直接确认安装。
- 验收状态更新（2026-07-26）：两平台升级验收均发现出厂代码缺陷，本版本的 `自动升级: yes` **未通过验证**——Windows 侧 Manager 误拒合法的 Velopack assets feed（裸数组被判 invalid JSON），Linux 侧 Dashboard 与 Manager 的心跳时间戳格式不一致导致升级健康检查恒失败。两侧缺陷在升级执行方（旧版本 Manager/实例代码）中，无法经自动路径自愈，请在含修复的后续版本发布说明指引下手工迁移。Linux 的本地 bundle 手工升级路径（`docker load` + `--pull never`）已验证可用。
