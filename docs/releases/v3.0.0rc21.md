# v3.0.0rc21

- 数据变更: no
- 配置变更: no
- 变更范围: runtime, dashboard, manager, deployment
- 自动升级: no
- 最低 Manager 版本: 1.0

## Changed

- Linux Manager 升级在 Bot 容器已就绪后，为 OneBot/QQ 登录和首个新控制心跳保留独立的启动窗口；RuntimeUnit 本地健康失败仍保持快速回退。

## Fixed

- 修复真实 Bot 或 Dashboard 停止接近 Docker 宽限期时，容器已经停止但 socket 响应超时导致 Linux 接管被误判失败的问题。
- 修复低配环境中真实 QQ Bot 首心跳超过 20 秒时，健康目标被过早删除并触发不必要回退的问题。

## Risk Notes

- 本 RC 用于从公开 rc20 基线验证 Linux 跨版本切换与回退、Windows 健康提交与根恢复流程；发布契约仍不开放 Manager 自动安装。
- 本版本包含 Manager 版本身份更新，默认通过官方发行包手工迁移；升级前应保留现有程序、配置与数据备份。
- 本版本不包含数据或配置 schema、Compose service、volume、network 或 deployment schema 迁移。
