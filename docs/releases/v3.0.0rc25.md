# v3.0.0rc25

这是配置系统与 Persona 功能的简化测试版本，供 Windows Portable 和 Linux Docker 实例验收。

## 主要变化

- Dashboard 配置页改为类型化表单，区分实例配置、Bot 配置和高级配置；配置文件只保存偏离默认值的字段。
- Bot 配置只保留单一 Master、好友口令、群邀请、默认模式、每日摘要和 Persona 高层设置。
- Persona 文本模型收敛为单一 DeepSeek 客户端，模型连接配置统一放在 `config/user.json`，内部按任务决定超时和思考模式。
- Persona 默认只提供响应式聊天；生活模拟使用单独开关，关闭时聊天不会触发生活事件。
- LLM 调用始终保存轻量元数据；只有开启 LLM Debug Trace 时保存完整请求、回复和工具参数。
- 每日摘要独立于 Persona 开关；配置 Master 后，即使 Persona 关闭也可接收固定模板摘要。
- 修复移除仓库默认配置后 Linux 镜像仍尝试复制 `config/`、导致镜像无法构建的问题。

## 删除的功能

- 删除主动分享、想念消息、旧消息生成器及相关暂停、状态和 `.ai mute` 命令。
- 删除关系评分、关系衰减、用户画像及其数据库和上下文链路。
- 删除多供应商模型路由、用户自带模型配置、旧管理员角色和大量内部策略配置。
- 删除 Manager、自动下载、自动安装、自动回滚和跨版本升级编排；Dashboard 只负责当前实例的启动、停止、重启、日志、配置、备份、清空和导入。

## 配置与数据

- 这是开发期破坏性配置切换：不读取旧配置字段，也不提供旧配置自动转换。请在新实例中通过 Dashboard 重新保存配置。
- `config/user.json` 保存 DeepSeek API Key、模型、接口地址、每日 AI 限额和日志设置；`config/bots/<QQ号>.json` 只保存该 Bot 的行为配置。
- 启用 Persona 时，角色目录必须同时包含 `character.yaml` 和 `skin.yaml`；`skin.yaml` 可以为空。
- 当前版本的目录导入和存档只按当前格式验收，不承诺兼容早期 RC 生成的配置或存档。

## 部署与更新

- Windows 只发布 Portable ZIP，包含 `DicePP.exe` 和 `DicePP-Runtime.exe`。请解压到新的空目录，不要覆盖运行中的旧目录。
- Linux 只发布 `ghcr.io/pear-studio/nonebot-dicepp:v3.0.0rc25` 单一镜像和单 service `docker-compose.yml`。
- 本版本没有自动升级入口。Linux 请拉取新镜像并重新创建容器；Windows 请下载新的 Portable ZIP。

## 验收注意

- 本版本仍是 RC。请先备份并在可丢弃的测试实例中验收，不要让它直接接管唯一一份生产数据。
- Web 日志发布地址仍没有内置默认端点，需要使用时请显式配置。
