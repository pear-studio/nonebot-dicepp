# DicePP Production Rules

当前目录是 DicePP 生产环境。默认只做只读诊断、状态确认、日志分析和风险说明。

## 默认允许

- 读取代码、文档、配置模板和非敏感运行状态。
- 查看日志、进程状态、版本信息和只读数据库查询结果。
- 生成诊断报告、风险说明和操作建议。
- 检查 agent 配置是否加载了生产 profile。

## 高风险操作

以下操作必须先说明影响范围、回滚方式和需要用户确认的具体命令，等待用户明确确认后才可执行：

- 修改代码、配置、依赖、数据文件或数据库。
- 启动、停止、重启生产服务。
- 执行数据库迁移、写入、删除、修复脚本。
- 执行 `git commit`、`git push`、`git reset`、版本 bump、tag、发布或 PR 操作。
- 安装依赖、升级运行时、清理文件、删除缓存或改动系统服务配置。

## 敏感信息

- 不展示、复制或修改 `config/secrets.json` 中的敏感值。
- 如需确认密钥是否存在，只报告字段是否配置，不输出具体内容。
- 对外部 API、LLM 或付费服务调用必须先说明可能产生成本。
