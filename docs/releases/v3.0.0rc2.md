# v3.0.0rc2

- 数据变更: no
- 配置变更: no

## Added
- 暂无。

## Changed
- Release 门禁改为复用 CI 测试套件，Docker 镜像和 Windows EXE 均需在门禁通过后才进入发布。
- Docker 镜像分层优化，第三方依赖层与源码层分离，减少普通代码更新时的重复拉取。
- Linux 部署文档明确发布镜像为主路径，源码构建仅作为无法拉取镜像时的附录方案。
- `docker-compose.yml` 支持通过 `DICEPP_IMAGE` 覆盖完整镜像地址，便于临时使用其他 registry。

## Fixed
- 修复 Windows EXE 漏收 `cryptography.fernet`，导致启动时 DicePP 插件加载失败的问题。
- `--smoke-check` 现在会检查 DicePP 插件入口导入链，避免关键依赖漏包仍通过冒烟测试。

- 该版本重点验证 release 门禁、Windows EXE 打包修复、Docker 镜像分层和 GitHub Prerelease 产物。
