# v3.0.0rc11

- 镜像: ghcr.io/pear-studio/nonebot-dicepp:v3.0.0rc11
- Windows: `DicePP-v3.0.0rc11-win64-Portable.zip`、独立 `DicePP-v3.0.0rc11-win64-Setup.exe` 和 Velopack feed
- 数据变更: yes
- 配置变更: yes
- 变更范围: runtime, dashboard, manager, deployment, windows, linux, data, config, documentation
- 自动升级: no
- 最低 Manager 版本: 1.0

## Added

- 新增常驻 DicePP Manager，统一管理 Bot 运行单元、归档恢复、维护操作和版本状态。
- Dashboard 新增归档、恢复预览、运行监控和版本更新界面。
- 发布包新增 Linux 离线镜像 bundle，以及 Windows Portable、Setup 和更新所需的 Velopack 产物。

## Changed

- DicePP 管理的配置、数据和用户内容使用稳定实例根目录，程序更新不再替换用户数据。
- Linux 标准部署调整为 Bot、Dashboard、Manager 三服务结构；Windows 标准部署由 Manager 管理本机运行单元。
- 归档恢复使用精确快照和可恢复事务；常规归档不包含用户 `content/`，完整归档才包含该目录。

## Fixed

- 修复归档、发布校验和升级事务中的状态恢复、配置仲裁与路径安全问题。

## Risk Notes

- 这是首个标准 Manager 基线 RC。现有无 Manager、旧式或非标准部署必须先按平台文档手工迁入，不能通过版本更新页直接升级。
- 本版本涉及数据布局、配置和部署拓扑。升级或迁入前请备份现有 `config/`、`data/` 与需要保留的 `content/`。
- 自动升级在本 RC 中明确关闭；完成 Windows 与 Linux 的真实升级、健康提交和失败回退验收前，不应把后续版本标记为自动升级兼容。
