# v3.0.0

- 镜像: ghcr.io/pear-studio/nonebot-dicepp:v3.0.0
- 数据变更: no
- 配置变更: no

## Added
- 发版系统: `version-release` (dev) + `version-deploy` (prod) + `deploy-docker` (prod) agent 技能
- `get_bot_version()` 运行时版本读取函数，从 `importlib.metadata` 派生
- `.github/workflows/release.yml`: tag push 自动构建 GHCR 镜像 + 创建 GitHub Release
- `docs/releases/` 目录: release metadata 和发版系统设计文档
- `make update` / `make update-version`: 镜像更新命令

## Changed
- `BOT_VERSION` 硬编码移除，版本号统一从 `pyproject.toml` 读取
- Dockerfile 构建方式: `uv sync --no-dev --frozen` 替代 `uv pip install .`，保证可复现
- Dockerfile 构建源默认值改为官方源，国内开发通过 docker-compose build args 覆盖
- `docker-compose.yml` 新增 `image:` 声明，同时保留 `build:`，支持镜像/源码双模式
- `scripts/deploy/linux/update.sh` 改为镜像/源码自动切换

## Fixed
- Dockerfile builder 阶段仅 COPY pyproject.toml 导致依赖安装不完整的问题

## Deprecated
- `BOT_VERSION` 常量已移除，使用 `get_bot_version()` 替代

## Risk Notes
- 此版本为发版系统基线，不包含数据库 schema 变更、配置格式变更或数据迁移
- 升级后 `.bot` 版本号显示从 `v3.0.260421.1` 变为 `v3.0.0`（从构建日期标识统一为标准 semver）
