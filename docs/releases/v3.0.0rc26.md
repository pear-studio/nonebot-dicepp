# v3.0.0rc26

这是 v3.0.0rc25 之后的修复版本，供 Windows Portable 和 Linux Docker 实例验收。

## 修复内容

- 修复 Bot 初次连接或重连时，NoneBot 连接回调尚未注册 DicePP Bot 导致首批消息、通知和请求事件被丢弃的问题；现在会等待注册完成后仅处理一次。
- 修复 Persona 分段回复后再次发送聚合全文、以及错误回执导致重复投递的问题；正文统一经分段通道发送，完成标记不再携带正文。
- 修复 Persona 日志输出未格式化的 `%s` 字面量，模型名和异常载荷摘要现在会正确显示。

## 配置与数据

- 无配置或数据格式变化，沿用 v3.0.0rc25 的配置结构。

## 部署与更新

- Windows 只发布 Portable ZIP，包含 `DicePP.exe` 和 `DicePP-Runtime.exe`。请解压到新的空目录，不要覆盖运行中的旧目录。
- Linux 只发布 `ghcr.io/pear-studio/nonebot-dicepp:v3.0.0rc26` 单一镜像和单 service `docker-compose.yml`。
- 本版本没有自动升级入口。Linux 请拉取新镜像并重新创建容器；Windows 请下载新的 Portable ZIP。

## 验收注意

- 本版本仍是 RC。请先备份并在可丢弃的测试实例中验收，不要让它直接接管唯一一份生产数据。
- Web 日志发布地址仍没有内置默认端点，需要使用时请显式配置。
