# v3.0.0rc19

- 镜像: ghcr.io/pear-studio/nonebot-dicepp:v3.0.0rc19
- Windows: `DicePP-v3.0.0rc19-win64-Portable.zip`、独立 `DicePP-v3.0.0rc19-win64-Setup.exe` 和 `velopack.win-x64.zip`
- 数据变更: no
- 配置变更: no
- 变更范围: deployment
- 自动升级: yes
- 最低 Manager 版本: 1.0

## Fixed

- 修复 Windows Portable 或安装版从 v3.0.0rc17 / v3.0.0rc18 自动升级时，回滚包事务布局不一致可能导致新 Manager 无法启动、程序回滚后旧 Manager 仍要求手工恢复的问题。
- Windows 更新事务现在兼容读取旧的分层回滚包布局，并为后续事务恢复使用旧 Manager 可识别的直接布局。

## Risk Notes

- 已在隔离 Portable 实例验证 v3.0.0rc17 到本版本的完整检查、下载、校验、归档、安装与健康提交，并通过目标 Manager 启动阶段的端口故障注入验证 UpdateGuard 可回滚程序、由原版 v3.0.0rc17 Manager 恢复事务。
- v3.0.0rc17 / v3.0.0rc18 发起的事务仍会先使用旧的分层回滚包布局；目标 Manager 启动后会在严格验证 Guard 身份后迁移兼容副本。如果 Velopack 在任何新版本代码执行前即失败并回滚，目标版本没有机会迁移旧请求，仍可能需要手工恢复。
- 本版本不包含数据、配置 schema、Compose service、volume 或 network 迁移。
