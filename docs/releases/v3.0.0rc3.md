# v3.0.0rc3

- 镜像: ghcr.io/pear-studio/nonebot-dicepp:v3.0.0rc3
- Windows: DicePP-v3.0.0rc3-win64.zip
- 数据变更: no
- 配置变更: yes

## Added
- 新增独立 Dashboard 镜像控制通道冒烟测试，确保镜像中可用 Bot 侧控制通道依赖。
- 新增 Windows Dashboard EXE 窄版 Playwright 冒烟测试，验证打包后的 Dashboard 可启动并展示首次初始化表单校验。
- 新增 Dashboard 管理员密码命令行初始化入口，Linux 部署可通过 CLI 完成首次初始化。

## Changed
- Dashboard 首次初始化按平台区分：Linux 禁用 Web 初始化，Windows 仅允许本机或局域网直连初始化。
- Dashboard 浏览器 smoke 在 Linux 环境下通过预置管理员密码聚焦登录与配置编辑流程，setup 表单校验改为独立前端路径覆盖。
- Dashboard 控制通道客户端改为显式检测静默断线、状态上报失败与鉴权失败，并进入重连退避。

## Fixed
- 修复 Dashboard Docker 镜像中项目包安装顺序，避免控制通道依赖未安装导致镜像 smoke 失真。
- 修复 `run_structured_collect` 合并额外工具时访问 ToolRegistry 私有字段的问题，改用公开工具列表 API。
- 修复群消息查询在相同时间戳下排序不稳定的问题。
- 修复 persona 日记测试 fixture 与 DailyEvent 模型契约不一致导致的 Fast Tests 失败。

## Deprecated
- 暂无。

## Risk Notes
- 这是发版链路验证用 RC，不作为正式生产版本部署。
- 不包含数据库 schema 变更或数据迁移。
- Dashboard 首次初始化策略有行为变化：Linux 用户需要使用命令行初始化管理员密码；Windows 用户仍可在本机或局域网直连地址初始化。
- 该版本重点验证 Dashboard 独立镜像、Windows EXE 打包、控制通道重连、首次初始化策略和 CI 测试门禁。
