# v3.0.0rc9

- 镜像: ghcr.io/pear-studio/nonebot-dicepp:v3.0.0rc9
- Windows: DicePP-v3.0.0rc9-win64.zip
- 数据变更: yes
- 配置变更: no
- 变更范围: runtime, dashboard, deployment, data
- 自动升级: yes
- 最低 Manager 版本: 1.0

## Added
- Dashboard 概览 tab：恢复 Bot 状态、运营统计、Persona 活跃度和 LLM 用量聚合视图。
- Persona Conversation 持久化：DM 和 Character 的对话记忆通过 ConversationRegistry 管理，支持 scope 感知的会话生命周期，对话上下文在重启后保留。

## Changed
- 部署文档和 `docker-compose.yml` 中协议适配器引用拓宽为 NapCat / LLOneBot 通用，不再仅提及 LLOneBot。

## Fixed
- 修复 persona coordinator 异常清理路径中的双锁竞态，消除并发场景下潜在的 KeyError。
- 修复 Dashboard 在未配置 Manager 时显示错误提示的问题，现仅灰化相关按钮。

## Risk Notes
- 这是 rc8 的后续 RC 版本，不作为正式生产版本部署。
- 数据变更：persona schema 从 V1 升级到 V2。`persona_session` 表新增 `scope_namespace`、`scope_key`、`summary_text` 列，`persona_session_message` 表新增 `message_stream_id`、`entry_type` 列，并创建 scope 相关索引。迁移通过 schema lifecycle 自动执行，无需手动操作。
- 无配置 schema 变更，升级无需修改配置文件。
