# v3.0.0rc5

- 镜像: ghcr.io/pear-studio/nonebot-dicepp:v3.0.0rc5
- Dashboard 镜像: ghcr.io/pear-studio/dicepp-dashboard:v3.0.0rc5
- Windows: DicePP-v3.0.0rc5-win64.zip
- 数据变更: yes
- 配置变更: yes

## Added
- Dashboard 新增概览 tab，聚合展示 Bot 运行状态、运营统计和 LLM 用量。
- Dashboard 配置编辑支持分组可折叠视图，Persona 配置独立为单独 tab。
- Dashboard 配置编辑与数据浏览界面支持中文标签和描述。
- Dashboard Bot 配置 tab 增加编辑模式开关与通用导航守卫，离开未保存页面时弹出确认提示。
- Dashboard 监控页面 SSE 实时推送替代轮询刷新，骨架屏替代全局 loading overlay。

## Changed
- Persona 统计维度拆分：消息数、指令数、掷骰数按群聊/私聊分别计数。
- Persona 日报重构为上下两段新格式，更清晰地区分统计概览和互动细节。
- Persona MiniMaxImageProvider.probe() 非超时异常改为向上传播，启用 LLM router 分类决策机制。
- Persona probe 路径感知错误分类，区分配额/鉴权等不可重试错误，避免无意义重试消耗资源。
- Persona structured_collect 工具层统一输出校验与自动纠正。
- `config/schema.json` 已移除，Dashboard 现在动态生成配置元数据，不再依赖静态 schema 文件。

## Fixed
- 修复 Dashboard 动态 provider 键元数据匹配错误，导致部分 provider 配置无法正常编辑。
- 补全 Dashboard 未保存编辑时的页面离开防护，避免误操作丢失修改。
- 修正 Dashboard 缓存重试逻辑，避免旧缓存数据被错误复用。
- Dashboard config_merged 接口过滤 `_comment` 开发者注释键，避免前端展示内部注释信息。
- 修复 Dashboard 内容管理查询 tab 不支持中文数据库名、需手动刷新的问题。
- Dashboard content_list 过滤 `.` 开头隐藏文件，避免展示 `.gitkeep` 等占位文件。
- Dashboard 登录后自动选中第一个已开启的 bot，减少手动选择步骤。

## Deprecated
- 暂无。

## Risk Notes
- 这是发版链路验证用 RC，不作为正式生产版本部署。
- UserStatInfo 存储结构新增群聊/私聊分离统计字段，旧数据反序列化兼容，无需执行迁移脚本。
- `config/schema.json` 已从仓库移除。Dashboard 通过 `scripts/gen_config_schema.py` 动态生成配置元数据，部署时不再需要该文件。
- 现有 `config/schema.json` 文件可安全删除，不影响 Bot 运行和 Dashboard 功能。
