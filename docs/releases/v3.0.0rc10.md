# v3.0.0rc10

- 镜像: ghcr.io/pear-studio/nonebot-dicepp:v3.0.0rc10
- Windows: DicePP-v3.0.0rc10-win64.zip
- 数据变更: yes
- 配置变更: yes

## Added
- 重建跑团日志管理：支持通过 `.log on/off/list/export/del` 管理日志，导出 TXT、DOCX，并按需显式发布网页。
- Persona 支持按角色作息发送早安、晚安及自定义时间点的主动分享消息。

## Changed
- Persona 统一对话结果提交和完整执行轨迹保存，改善 thinking 模型的工具调用、纠正轮与长期上下文衔接。
- 群聊与私聊上下文统一记录时间、账号和昵称，连续对话及 `.jrrp` 能更可靠地区分不同玩家。
- `.bot`、`.help` 和关于信息统一显示安装包版本、作者、贡献者及项目链接。
- 日志网页发布改为显式操作；本地日志记录和导出不再依赖网页服务可用性。

## Fixed
- 修复 Persona 主动分享跨午夜重复触发、并发挂起及失败后错误标记为已发送的问题。
- 修复私聊 `to_me` 语义不一致、Persona 回复绕过日志记录及文件交付结果污染聊天历史的问题。
- 修复配置规范化时注释丢失，并为旧日志网页配置提供自动迁移。
- 修复 Agent Run 未准确记录实际模型，以及多人群聊中说话人身份传递不完整的问题。

## Deprecated
- 移除旧日志指令 `.log new/end/halt/get/publish/set/stat`；请改用 `.log on/off/export/list`。

## Risk Notes
- 这是 rc9 的后续 RC 版本，不作为正式生产版本部署。
- 升级前必须备份 `data/` 和 `config/`。旧版 `log.db` 的已知日志结构会被事务性重建，旧日志记录不会迁移；如需保留，请在升级前完成导出或另行备份数据库。
- Persona schema 从 V2 升级到 V3，为会话消息新增 `provider_context` 字段。迁移由 schema lifecycle 自动执行，无需手动操作。
- 旧 `log.upload_endpoint` 和 `log.upload_token` 会迁移到 `log.web`；`log.upload_enable` 不再使用，网页发布仅由显式日志指令触发。
- 已移除旧的 Persona 事件阈值/延迟及分段回调配置，新增主动分享日程配置且默认关闭。配置加载器会规范化配置文件并保留 `_comment*` 注释。
